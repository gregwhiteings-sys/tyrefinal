# TYRECYCLE | TYRETRACK V5 — Windows build package

This package is derived from the source ZIP uploaded on 13 October 2026.
The V5 Python source already includes separate recorded-video TEST dashboard metrics and OAK-only production dashboard metrics.

## Build in GitHub Actions
1. Create a **new, empty** GitHub repository (or clean branch).
2. Upload the **contents** of this ZIP to the repository root, retaining `.github/workflows/` exactly. Do not upload a folder containing all the files; the Python scripts must be at the repository root.
3. Open **Actions** > **TyreTrack V5 Compatibility Build** > **Run workflow**. This uses pinned CPU PyTorch and is the recommended first attempt.
4. Wait for completion. Under the workflow run's **Artifacts**, download `TyreTrack-V5-Compat-Windows-Portable`.
5. Extract the complete portable folder. Run `TyreTrack.exe` from inside the extracted folder. **Do not move the EXE out of the folder.**
6. If it fails, download `TyreTrack-V5-Compat-Diagnostics` and inspect `startup_output.txt` and `data/tyretrack.log`. The app is built in `--windowed` mode, so there is no command prompt.

Alternate: **TyreTrack V5 Windows Portable** workflow uses the newer dependency resolver.

## Email configuration
Put `email_config.ini` inside `data/private_config/` next to the portable EXE. The app creates a placeholder file automatically if missing.

[EMAIL]
sender_email = your_gmail@gmail.com
sender_app_password = your_google_app_password
recipient_email = recipient@example.com

Never upload a populated `email_config.ini` to GitHub.

## Important checks
- Recorded video should show TEST MODE and update test session counters; test results must not appear in OAK production totals.
- Confirm live OAK-D connection, frame rate, counting, classification, 05:00–17:05 Brisbane schedule, no-count alerts, and actual email delivery **on the Australian Windows PC**.
- Build success and a short startup smoke test are not substitutes for field testing.
- Keep the previous working TyreTrack installation untouched.
- This ZIP contains no Windows executable: the EXE is generated by GitHub Actions on Windows.
- No logo/icon file was supplied in this ZIP, so the EXE will use the default application icon until a custom .ico is provided.
